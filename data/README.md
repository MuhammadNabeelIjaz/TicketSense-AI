# Data Directory

This directory stores datasets and runtime correction logs for TicketSense-AI.

Dataset source details, licensing terms, and data privacy/sanitization information will be documented here once the dataset is finalized.

## Subdirectories

- `raw/`: Original, immutable dataset downloads (never edited directly; git-ignored).
- `processed/`: Cleaned data, engineered features, and train/test splits (git-ignored).
- `corrections/`: Runtime manual corrections saved by the application (git-ignored).
